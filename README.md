# LinkedIn covers

Title-card images for my LinkedIn posts, generated automatically and hosted
here so [Buffer](https://buffer.com) and [Publora](https://publora.com) can
attach them to a post via a public image URL — neither service accepts a
file upload, only a link.

This repo is public because the images end up on LinkedIn anyway; nothing
personal lives here. The actual automation, story bank and voice profile
stay private in a separate local project.

Images: `covers/YYYY-MM-DD-<slug>.png`, 1200×627, generated from
`covers/template.html` in [linkedin-skills](https://github.com/andrea-gervasoni).
